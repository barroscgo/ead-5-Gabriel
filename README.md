# Sistema de Cadastro

## Visão Geral
Este projeto consiste em uma aplicação web simples para o cadastro de usuários. O objetivo é permitir que os usuários se cadastrem fornecendo nome e email, e também a possibilidade de acessar um formulário de contato. 

## Funcionalidades Principais
- Cadastro de usuários com nome e email.
- Redirecionamento entre as páginas: cadastro de usuários, formulário de contato e página sobre.
- Exibição dos usuários cadastrados.

## Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização e responsividade 
- **JavaScript:** Lógica para a interatividade
